Profile: Nigerian software developer and technology founder

Kpono-Abasi Akpabio is a software engineer and technology entrepreneur in Nigeria, and the founder of Almond Systems. His work spans enterprise software development, backend engineering, ecommerce platforms, financial technology, API development, mobile applications, cloud infrastructure and production operations.

He has worked across Java enterprise applications, PHP and Laravel systems, Magento commerce platforms, Python development, and modern JavaScript and TypeScript applications using Node.js and React. His engineering focus is on building dependable systems: well-structured APIs, data-intensive applications, integrations, deployment pipelines and maintainable production software.

His project experience includes ecommerce migrations and extensions, headless Magento and GraphQL APIs, banking and financial applications, mobile-connected services, POS implementation, and web platforms. He also leads delivery and implementation work through Almond Systems.

Selected engineering experience and projects

Magento engineering, ecommerce migration and headless commerce

Magento experience includes work on the migration of Ajebomarket from Magento 1 to Magento 2, ecommerce platform customisation, integrations and API development. Work on the Konga (formerly Yudala) platform included Magento development and API integration supporting its mobile application. On the MTN eShop project, work included Magento GraphQL APIs for a headless architecture and customer-facing content and product experiences.

Banking, financial applications and enterprise Java

Enterprise Java experience includes Sterling Internet Banking and OTP server token authentication, alongside financial and stockbroking application work such as Nigerian Stockbrokers accounts and Global View accounts. Related technologies have included Java enterprise application frameworks, application servers and web application stacks.

Backend systems, APIs and business applications

Backend and full-stack delivery spans Node.js, React and TypeScript applications, PHP and Laravel systems, Python development, relational databases and service integrations. Project work includes web applications and operational platforms where API design, data integrity, authentication and reliable deployment are important.

POS software implementation

Through Almond Systems, the founder personally collaborates under a white-label delivery arrangement to implement and deploy Revire POS. This provides practical implementation experience in point-of-sale software deployment and business operations workflows.

Cloud infrastructure, Linux and DevOps

Infrastructure work includes Linux server administration, Docker-based deployments, Nginx reverse proxy configuration, database operations, backups, monitoring and application hosting across cloud environments including AWS and Google Cloud Platform.

Web platforms and digital delivery

Experience also includes WordPress and WooCommerce development, website migrations and maintenance, ecommerce integrations, performance and search optimisation, and building digital platforms for business use.
